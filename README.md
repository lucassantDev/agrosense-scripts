# AGROSENSE 🌱

**`projeto integrador`**
**`desenvolvimeto web`**


O **AgroSense** é uma plataforma web desenvolvida como parte do **Projeto Integrador do 2º Período da Faculdade Senac**.  
O objetivo do sistema é **aproximar Agricultores, o IPA (Instituto de Pesquisa Agronômica) e as Cooperativas**, criando um ambiente simples e intuitivo para comunicação, orientação e suporte técnico.

---

## 🚀 Tecnologias Utilizadas

### **Frontend**
- React.js  
- React Router DOM (navegação entre páginas)  
- JavaScript (ES6+)  
- CSS (arquitetura modular)  

### **Ferramentas**
- Vite  
- Lucide React (ícones)  
- Git e GitHub
